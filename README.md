# tapnode

Tap identifiers and node tokens for idempotent workflows.

**Site:** https://theworker02.github.io/tapnode/

## Install / run

```bash
git clone https://github.com/theworker02/tapnode.git
cd tapnode
node src/cli.js
node --test
```
